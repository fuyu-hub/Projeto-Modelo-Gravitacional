    Configurações

    Parâmetros do Algoritmo

    Ajuste os parâmetros de execução do Modelo Gravitacional. Estes valores são lidos sempre que você executa uma nova análise ou um cenário interativo.

    Define o limite de iterações para o algoritmo de Furness convergir.
    Define o critério de parada baseado no erro relativo máximo entre as iterações.
    Se desativado, o modelo atribui uma impedância infinita às viagens que começam e terminam na mesma zona.
    Define a fórmula matemática para calcular a resistência entre as zonas. α, β e γ são os pesos definidos nos cenários.

    Sobre o Projeto

    Esta aplicação implementa o Modelo Gravitacional de Alocação de Viagens, utilizando o método de Fator Duplo (Doubly Constrained).

    Metodologia

    O modelo estima uma matriz Origem-Destino (OD) com base na atratividade entre zonas, que é proporcional à sua capacidade de geração e atração, e inversamente proporcional a uma função de impedância (custos de tempo, distância e preço).
