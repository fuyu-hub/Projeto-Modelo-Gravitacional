Configurações

Parâmetros do Algoritmo

Ajuste os parâmetros de execução do Modelo Gravitacional. Estes valores são lidos sempre que você executa uma nova análise ou um cenário interativo.

Define o limite de iterações para o algoritmo de Furness convergir.
Critério de parada baseado no erro relativo máximo entre iterações (ex: 0.0005 = 0.05%).
Se desativado, o modelo atribui impedância infinita às viagens que começam e terminam na mesma zona.
Define a fórmula para calcular a resistência entre zonas. C1, C2... são os custos (resistências) e p1, p2... são os parâmetros definidos nos cenários ou sliders.

Sobre o Projeto

Esta aplicação implementa o Modelo Gravitacional de Alocação de Viagens, utilizando o método de Fator Duplo (Doubly Constrained) e permitindo múltiplos fatores de resistência.

Metodologia

O modelo estima uma matriz Origem-Destino (OD) com base na atratividade entre zonas, que é proporcional à sua capacidade de geração e atração, e inversamente proporcional a uma função de impedância configurável (baseada nos custos definidos pelo utilizador).
